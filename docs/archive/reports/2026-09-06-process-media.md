## Access/hosting relations that must not become flow wires

- Jellyfin and Navidrome expose Internet-reachable family endpoints with native authentication rationale; this is declared audience/reachability. Calibre-web/Komga/Suwayomi declare selected proxy-auth exempt API paths. Stremio has operator audience; Filmder's `audience="public"` does not itself prove public Internet routing. See each `manifest.nix`; no live Caddy/identity test performed.
- Jellyfin read-only mount visibility and users/media membership grant access, but do not assert every visible path is scanned. Navidrome has a concrete MusicFolder; Komga root registration remains a manual step.
- Calibre-web and Komga receive RW access to the whole library; Suwayomi is bound to manga; Lidarr to downloads+music; Bazarr/Sonarr/Radarr to downloads. This is current authority breadth, not evidence that each process writes every permitted tree.
- Shared Unix media group, directory setgid/umask and Btrfs subvolume boundaries control possible file operations. They are not a file-transfer process and cannot replace explicit read/import/write transitions.
- `after` and `wants` are startup constraints; they do not prove remote readiness or data availability. Recyclarr and Filmder explicitly show this distinction.

## Source tensions / unknowns to preserve in the model

1. **Ingest conflict alert:** script exits3 on quarantine, but the unit declares `SuccessExitStatus=[3]` while its comment says OnFailure should fire. Those declarations do not establish the claimed failure-alert transition; model conflict as logged/quarantined success-status-with-operator-action until separately resolved. [unit:111](../../../nix/modules/services/music-ingest/runtime.nix#L111), [script:154](../../../nix/modules/services/music-ingest/music-ingest.sh#L154).
2. **Lidarr hardlink claim:** prose says hardlinks, but source declares music under `@library` and completed downloads under `@downloads`, which are distinct subvolumes. Record an import/copy relation with mechanism unverified, rather than inheriting the shows/movies hardlink law.
3. **Filmder “atomic publish”:** script renames existing `dist` away before renaming `dist.new` into place. Each rename is atomic; an uninterrupted directory-presence postcondition is not established by this sequence. Build's secret value is not part of its commit sentinel, so unchanged Git commit can skip rebuilding after token change. These are observed transition/guard shapes, not live failure claims. [filmder:101](../../../nix/modules/services/filmder/runtime.nix#L101), [filmder:119](../../../nix/modules/services/filmder/runtime.nix#L119).
4. **Metadata bootstrap:** Calibre initialization suppresses failure; do not equate preStart completion with initialized metadata.
5. **State-path aliases:** Seerr service versus jellyseerr backup identity, and DynamicUser private paths, require upstream module or evaluated-unit confirmation before rewriting storage identity. Current table reports declared paths only.
6. **External internals:** upstream daemon schedulers, transcoder worker topologies, extension execution, browser TMDB calls and physical runtime performance are not specified sufficiently in the inspected repo. Existing package declaration is not proof of a nested process graph.
7. **Quiescence versus readiness:** qBittorrent paused does not mean arr state is absent; Filmder serving enabled does not mean artifact exists; backup intent exists while backup delivery is disabled. These require different process states in any rewrite.
